# STC8H1K08 八路 PWM 固件设计文档

状态：已评审定稿（决策见 §7，均已确认）
版本：v2（协议对原始需求做了修订，理由见 §5）
工具链：PlatformIO (`intel_mcs51`) + SDCC + FwLib_STC8（Apache-2.0，vendored 于 `lib/FwLib_STC8/`）

---

## 1. 功能概述

- 主控 STC8H1K08（8 KB Flash / 256 B IRAM / 1 KB XRAM）。
- 通过 UART1（P3.6/RXD、P3.7/TXD，8N1）接收主控 MCU（ESP32-C3）命令，配置 8 路 PWM 的频率与占空比。
- P3.0/P3.1 保留给 STC ISP 下载，不作他用。
- P1.1：初始化完成指示 LED，初始化完成后输出高电平并保持。
- P1.3：PWM 已配置指示，成功应用任一设置命令后输出高电平；急停后拉低。
- 上电默认：8 路输出全部恒低（安全态），无掉电保存（EEPROM）需求。

## 2. 引脚分配

| 逻辑通道 | 硬件 | 引脚 | 说明 |
|---|---|---|---|
| CH0 | PWM1P (PWMA.1) | P1.0 | PWMA 默认脚 |
| CH1 | PWM2P (PWMA.2) | P1.2 | PWMA 默认脚 |
| CH2 | PWM3P (PWMA.3) | P1.4 | PWMA 默认脚 |
| CH3 | PWM4P (PWMA.4) | P1.6 | PWMA 默认脚 |
| CH4 | PWM5P (PWMB.1) | P1.7 | 经 `PWMB_PS` 切脚（=01） |
| CH5 | PWM6P (PWMB.2) | P5.4 | 经 `PWMB_PS` 切脚（=01） |
| CH6 | PWM7P (PWMB.3) | P3.3 | 经 `PWMB_PS` 切脚（=01） |
| CH7 | PWM8P (PWMB.4) | P3.4 | 经 `PWMB_PS` 切脚（=01） |

| 其他功能 | 引脚 | 说明 |
|---|---|---|
| UART1 RXD | P3.6 | 接主控 TXD |
| UART1 TXD | P3.7 | 接主控 RXD |
| ISP RXD/TXD | P3.0/P3.1 | 仅下载用，固件不配置 |
| LED 初始化指示 | P1.1 | 初始化完成后恒高 |
| LED PWM 已配置指示 | P1.3 | 设置命令成功后高，急停后低 |

引脚冲突核查（已对照数据手册 §2.1.2 管脚图 / §3.1.5 PWMx_PS，QFN20 与 TSSOP20 同引脚序）：

- P1.1/P1.3 是 PWMA 互补输出 PWM1N/PWM2N 的默认脚（P1.1 另为 TxD2，P1.3 另为 MOSI），但本固件只用 PWMxP，互补输出全部禁用（`PWMA_ENO`、`PWMA_CCERx` 对应位不置 1），UART2/SPI 不启用，P1.1/P1.3 归 GPIO。
- P3.3/P3.4 也是 PWMA.4 互补对的可选脚（`C4PS=11`），本固件 PWMA.4 保持默认组（`C4PS=00`，PWM4P=P1.6）且 PWM4N 禁用，不影响 CH6/CH7。
- P5.4 是 MCLKO 可选脚，未启用时钟输出；**ISP 下载时 P5.4 必须保持普通 I/O**（若在 ISP 选项中设为 RST 复位脚，PWM6 输出即失效且复位低有效，会被 PWM 波形干扰）。
- 除 P3.0/P3.1 外所有 IO 上电为高阻输入（数据手册 §2.1.2 注意），P1.1/P1.3 及 8 路 PWM 脚均需显式配置为强推挽输出。
- 数据手册 `C2PS=00` 一行把 PWM2P 标为 "P1.2/P5.4"，但逐脚功能表中 P5.4 仅列 MCLKO/RST/PWM6_2、PWM2P 仅在 P1.2；按 P1.2 实现，上电验证时示波器确认 P5.4 上无 PWM2P 泄漏（上电验证项）。
- ADC_VRef+（pin 9）必须接 VCC 或外部参考源，不得浮空（硬件侧注意，非固件）。

## 3. 硬件约束（协议设计的决定性因素，均据数据手册 §20 / §6）

1. **频率按组共享**：数据手册 §20 开篇——"分成两组周期可不同的 PWM…PWMA 和 PWMB…可分别单独设置"，每组一套 `PWMx_PSCR`/`PWMx_ARR`（寄存器映射 FED0H/FEF0H），组内 4 通道共享。
   → **全芯片只有 2 路独立频率**（A 组 CH0–CH3、B 组 CH4–CH7），"每通道独立频率"在硬件上不可实现。占空比每路独立（`PWMx_CCRx`）。
2. **占空比分辨率随频率变化**：边沿对齐频率公式（数据手册 §20.7.19）$f_{pwm} = \dfrac{SYSCLK}{(PSCR+1)(ARR+1)}$，一个周期的计数步数 $N = ARR+1$，占空比实际步进 $1/N$。
   - $N \ge 10000$ 时才有 0.01%（协议 1/10000）的真实分辨率；
   - 高频必然变粗：如 SYSCLK=22.1184 MHz、65535 Hz 时 $N \approx 338$，步进约 0.3%。协议的 0~10000 编码保留，但**实际分辨率为 $1/N$**，固件按四舍五入量化。
3. 16-bit PSCR/ARR：手册 §20 载明预分频值 1~65535 可任设，频率下限远低于需求，无约束。
4. **PSCR/ARR/CCR 均为预装载寄存器**（§20.7.19："PSCR 包含了当更新事件产生时装入…的值…为了使新的值起作用，必须产生一个更新事件"）——频率、周期、占空比在周期更新事件**同时原子生效**，批量更新不撕裂周期。

## 4. 通信协议 v2

### 4.1 帧格式（请求，主控 → STC）

| 偏移 | 内容 | 说明 |
|---|---|---|
| 0 | `0xAA` | 帧头 1 |
| 1 | `0x55` | 帧头 2 |
| 2 | 命令 | 见 §4.3 |
| 3 | 长度 | 数据区字节数，0–32 |
| 4..4+len-1 | 数据 | 见各命令 |
| 4+len | CRC8 | 覆盖字节 2..3+len（命令+长度+数据），多项式 `0x07`，初值 `0x00`，不反转、无异或输出（CRC-8/ATM 参数） |

所有多字节整数**大端序**。频率 `uint16`，单位 Hz，范围 0–65535；占空比 `uint16`，0–10000 对应 0.00%–100.00%。

CRC 测试向量（协议一致性测试用）：

```
CRC8(01 02 03 04)              = 0xE3
CRC8(04 00)                    = 0x54   (急停帧的 命令+长度)
CRC8(02 03 00 13 88)           = 0x27   (单通道帧的 命令+长度+数据)
```

### 4.2 应答帧（STC → 主控）

相同帧头，命令字节 `| 0x80`，避免与请求混淆：

| 偏移 | 内容 | 说明 |
|---|---|---|
| 0-1 | `AA 55` | 帧头 |
| 2 | 请求命令 `| 0x80` | |
| 3 | 长度 | 1+N |
| 4 | 状态码 | 见下 |
| 5.. | 数据 | 查询命令的回读数据 |
| 末 | CRC8 | 同 §4.1 |

状态码：`0x00` OK；`0x01` CRC 错；`0x02` 长度错；`0x03` 参数错（通道号越界等）；`0x04` 急停锁存中，设置命令被拒绝。

### 4.3 命令表

| 命令 | 名称 | 数据区 | 行为 |
|---|---|---|---|
| `0x01` | 全量设置 | `fA_H fA_L fB_H fB_L d0_H d0_L ... d7_H d7_L`（20 B） | 设置 A 组（CH0–3）频率 fA、B 组（CH4–7）频率 fB 和 8 路占空比；成功后 P1.3 置高 |
| `0x02` | 单通道占空比 | `ch(0–7) d_H d_L`（3 B） | 只改该路占空比，频率不变 |
| `0x03` | 全量占空比 | `d0_H d0_L ... d7_H d7_L`（16 B） | 频率不变，8 路占空比全量更新 |
| `0x04` | 急停 | 空（len=0） | 8 路立即恒低，P1.3 拉低，进入锁存态 |
| `0x05` | 恢复 | 空 | 解除急停锁存，按保存的配置恢复输出 |
| `0x06` | 状态查询 | 空 | 应答数据：`flags(1) fA_H/L fB_H/L d0..d7(16)`（21 B）；flags bit0=急停锁存，bit1=已配置过 |
| `0x07` | 版本查询 | 空 | 应答数据：`协议版本(1) 固件主版本(1) 固件次版本(1)` |

### 4.4 语义定义

- 频率 = 0：该组 4 路输出**恒低**（安全态），该组内占空比值保留但无效；再次设为非 0 恢复。
- 占空比 = 0：该路恒低；占空比 = 10000：该路恒高（由输出模式强制，不依赖 CCR 计算）。
- 量化：$N = ARR+1$，$CCR = \mathrm{round}(duty \times N / 10000)$，实际频率 $= SYSCLK / ((PSCR+1)\cdot N)$。
- 急停：所有通道强制恒低（输出模式 AlwaysLow），锁存；只有 `0x05` 能恢复，期间 `0x01/0x02/0x03` 回 `0x04` 状态码，`0x06/0x07` 正常应答。
- 恢复：使用急停前保存的频率/占空比配置重新加载。
- 帧间超时 5 ms：两字节间隔超过 5 ms 判定帧作废，状态机回帧头搜索态（防半帧粘连）。约等于 115200 波特率下 57 字节时间。
- 长度合法性：len > 32 → 回 `0x02` 状态码并重新同步；未知命令 → 回 `0x03`。
- CRC 错：丢弃，回 `0x01`（命令字节照收并回显；若命令字节本身已损坏，应答可能回错命令号，主机以 CRC 过滤）。

### 4.5 波特率与时钟（已定）

- UART1：8N1，无流控，波特率 **115200**（可编译期配置）。波特率源 Timer2 1T 模式，最快 FOSC/4（§2 特性）。
- **系统时钟由 ISP 下载时设定**（数据手册 §6.2：ISP 下载软件按所选频率自动微调 IRC，常温误差 ≤±0.3%；全温区温漂 -1.35%~+1.30%）。固件**不写 IRCBAND/VRTRIM/IRTRIM/LIRTRIM**——手册明确警告不调频率时这 4 个寄存器不能随意修改，否则运行频率会变。
- 固件只显式设 `CLKDIV`（§6.2.4：**复位值 = 0x04，即复位后 SYSCLK=MCLK/4**；置 0 后 SYSCLK=MCLK=ISP 设定的 IRC 频率）。编译宏 `__CONF_FOSC` 必须与 ISP 设定一致。
- **默认 22.1184 MHz**（20 MHz 频段直接可得、≤35 MHz 合规；115200/9600/460800 波特率分频零误差：$22118400/(4\times115200)=48$ 整除；65 kHz PWM 有 338 计数/周期）。
- 备选（改 ISP 频率与 `__CONF_FOSC` 即可切换）：24 MHz（115200 误差 0.16%）；11.0592 MHz SYSCLK（=22.1184 MHz+CLKDIV 2，分辨率减半）；36.864 MHz（超出手册建议上限，不用于量产）。

## 5. 相对原始协议的优化点

| # | 原协议问题 | v2 处理 |
|---|---|---|
| 1 | **每通道独立频率硬件不支持**（§3.1），原 `0x01`/`0x02` 的频率字段 8 路中 6 路是假的 | 改为 A/B 两组频率：`0x01` 20 字节（2 频率+8 占空比）；单通道命令去频率化 |
| 2 | 无任何应答，主控无法知道设置是否生效、CRC 是否错 | 增加应答帧（ACK/NACK+状态码），命令 `|0x80` 回显 |
| 3 | 无回读，主控与从机状态可能漂移 | `0x06` 状态查询回读当前配置+状态位 |
| 4 | 急停后无恢复定义 | 显式 `0x05` 恢复；急停锁存期间拒绝设置命令（fail-safe） |
| 5 | CRC 覆盖范围、初值未定义 → 两侧实现易不一致 | 明确 CRC-8/ATM 参数 + 测试向量 |
| 6 | 无帧同步健壮性规定：长度字段损坏会带崩解析 | len 上限 32 强校验、5 ms 帧间超时重同步、坏帧逐字节找 `AA 55` |
| 7 | 0 Hz / 0% / 100% 语义未定义 | §4.4 明确：0 Hz=恒低安全态、0%=恒低、100%=恒高（模式强制） |
| 8 | 无版本协商 | `0x07` 版本查询，协议版本字节 1 起步 |
| 9 | 命令 0x02 单通道设频率与组共享频率矛盾 | 单通道只设占空比；改频率必须走 `0x01`（整组），语义诚实 |

可选增强（v2 未采用，避免过度设计；需要时可平滑加）：

- 从机地址字节/广播地址（多机 RS485 总线用）——当前点对点不需要。
- 应答中带序号字节（请求-响应配对）——单线程问答、顺序执行时冗余。
- 占空比 0~1000 简化编码——0~10000 成本相同，保留更高精度。
- 心跳/看门狗（主控失联 N ms 自动急停）——建议主控侧实现；若要从机侧做，可在协议加 `0x08` 喂狗命令，见 §7-Q3。

## 6. 固件架构

```
main.c ── 初始化(时钟/GPIO/PWM/UART/Timer0) ── 主循环
  │
  ├─ uart_io.c   UART1 中断收发、环形缓冲(RX 64B)、阻塞发送
  ├─ protocol.c  CRC8 + 帧解析状态机（纯 C，可在主机端 gcc 单测）
  │                proto_feed_byte(b, now_ms) → 事件: FRAME_OK / ERR_CRC / ERR_LEN / ERR_NONE
  ├─ pwm_ctrl.c  频率→(PSCR,ARR) 换算、占空比→CCR 量化、组/单路应用、急停/恢复、状态回读
  └─ tick        Timer0 1 ms 中断（1T 16 位自动重载，定时值 = 65536 - SYSCLK/1000），驱动帧超时
```

- 中断向量（数据手册 §12.5 例程）：Timer0 = 1，UART1 = 4；本芯片仅 T0/T1/T2 三个定时器（§2 特性），T2 专供 UART1 波特率，帧超时用 T0，资源无冲突。

- RX 路径：UART1 ISR 只做 `SBUF → 环形缓冲 + 时间戳`；主循环取字节喂状态机，完整帧再解析命令。不丢字节的裕量：应答最长约 22 字节（1.9 ms @115200）期间环形缓冲 64 B 远大于流入量。
- 应答发送：主循环阻塞发送（帧短，简单可靠），ISR 继续收数。
- 8051 资源预算：解析缓冲 32 B、环形缓冲 64 B 放 DATA；32 位除法仅在命令处理路径调用（SDCC 库函数），主循环空闲时无运算。目标代码 < 8 KB（链接期 `--code-size 8192` 强制）。
- 命令处理期间对 PWM 寄存器的写入利用预装载，周期边界原子生效（§3.4）。

### 6.1 频率换算（pwm_ctrl）

已知 $SYSCLK$、目标 $f$（1..65535 Hz）：

```
total = SYSCLK / f                        # 每周期总分频数
if total <= 65535:  PSCR = 0;             N = total
else:               PSCR = ceil(total/65535) - 1;  N = total / (PSCR+1)   # N ≤ 65535
ARR = N - 1
```

占空比：`CCR = (duty * N + 5000) / 10000`（32 位中间量）；`duty==10000` → 输出模式 AlwaysHigh；`duty==0` 或 `f==0` → 恒低。

## 7. 已确认决策（2026-10-12 评审）

| 问题 | 决策 |
|---|---|
| Q1 频率模型 | **v2 双组频率**：`0x01`=20 B（fA、fB、8×占空比），`0x02` 单通道只设占空比（3 B） |
| Q2 应答机制 | **完整 ACK/NACK + 查询**：每命令应答（cmd\|0x80 + 状态码），`0x06` 状态回读、`0x07` 版本查询 |
| Q3 急停语义 | **锁存 + 显式恢复 `0x05`**；不做从机侧失联看门狗（主控侧负责安全监控） |
| Q4 系统时钟 | **22.1184 MHz**（ISP 下载时设定；固件不动 IRC 微调寄存器，只清 CLKDIV） |
| Q5 波特率 | **115200** 8N1 |

由此命令表/语义按 §4.3、§4.4 定稿实现；若日后需要失联急停，可平滑增加 `0x08` 喂狗命令（§5 可选增强）。

## 9. 上电验证清单（硬件联调）

1. P1.1 初始化后恒高；上电默认 8 路恒低。
2. 串口回环：`0x07` 版本查询收到应答，CRC 正确；`0x06` 回读与下发一致。
3. 逐路点亮：`0x02` 各通道 50%，示波器/万用表确认 CH0–CH7 引脚对应关系；确认 P5.4 无 PWM2P 泄漏、P1.1/P1.3 无 PWM1N/PWM2N 波形。
4. 频率准确性：A/B 组设 50 Hz / 20 kHz / 65 kHz，测实际频率（允许量化误差 + IRC ±0.3%）；跨组不同频率互不影响。
5. 边界：占空比 0/10000 为恒低/恒高；频率 0 为恒低；65535 Hz 可设。
6. 急停/恢复：`0x04` 后全部恒低、P1.3 灭、设置命令被拒（状态 0x04）；`0x05` 恢复原配置。
7. 容错：半帧 + 5 ms 间隙后下一帧正常解析；坏 CRC 回 0x01；len 超限回 0x02。
